# คู่มือการทดสอบ API ด้วย Postman (สำหรับนำเสนอและเก็บคะแนนกรรมการ)
**อ้างอิงตาม:** ใบประเมินการให้คะแนนการแข่งขันทักษะเทคโนโลยีสารสนเทศด้านโปรแกรมและเครือข่ายด้วยกระบวนการ DevOps (ระดับ ปวส.)  
**หมวดที่ประเมิน:** ส่วนที่ 4 ซอฟต์แวร์และการประยุกต์ (ข้อ 4.4 และ ข้อ 4.5 รวม 15 คะแนน)

---

## 🌐 คำถามสำคัญ: ตอนทดสอบ API ต้องใช้ URL ไหน?

ในระบบ Postman Collection นี้ เราได้ตั้งค่าตัวแปรกลาง `{{base_url}}` ไว้ให้เรียบร้อยแล้ว โดยคุณสามารถเลือก **Environment (มุมขวาบนของ Postman)** ได้ 2 แบบตามสถานการณ์:

| สภาพแวดล้อมที่ทดสอบ | Environment ที่ต้องเลือก | URL ที่ระบบใช้ยิง | เหมาะกับตอนไหน |
| :--- | :--- | :--- | :--- |
| **ยิงผ่าน Domain (แนะนำ)** | **`DevOps TNK (Domain: backend.group3.vec)`** | **`https://backend.group3.vec`** | ยิงจากเครื่อง Windows หรือเมื่อมีการตั้งค่า `/etc/hosts` ชี้โดเมนแล้ว (ผ่าน Caddy HTTPS ปลอดภัย 100%) |
| **ยิงตรงเข้าเครื่อง (Local/IP)** | **`DevOps TNK (Localhost: 5000)`** | **`http://localhost:5000`**<br>*(หรือ `http://<IP_UBUNTU>:5000`)* | ยิงตรงเข้าเครื่อง Ubuntu เซิร์ฟเวอร์ หรือกรณีที่เครื่อง Windows ยังไม่ได้แก้ไฟล์ hosts |

> 💡 **สรุป:** ถ้าอยู่บนเครื่อง Windows ที่แก้ `/etc/hosts` เรียบร้อยแล้ว ให้เลือก **`https://backend.group3.vec`** ได้เลยครับ! หรือถ้าอยากยิงตรงเข้าพอร์ตหลังบ้าน ก็แค่สลับไปเลือก **`Localhost: 5000`** ได้ใน 1 คลิก!

## 🚀 วิธีนำเข้าไฟล์ Preset เข้าสู่ Postman (3 ขั้นตอน)

ไฟล์ทั้งหมดถูกเตรียมไว้ให้แล้วในโฟลเดอร์ `docs/postman/` หรือบนหน้า Desktop โฟลเดอร์ **`postman-devops-tnk`**:
1. **เปิดโปรแกรม Postman** ➔ กดปุ่ม **`Import`** (อยู่มุมบนซ้าย)
2. **ลากไฟล์ทั้ง 3 ไฟล์ต่อไปนี้เข้าไปใน Postman:**
   - `devops-tnk.postman_collection.json` (ชุดคำสั่งยิง API ที่แยกตามรหัสเกณฑ์ข้อสอบ)
   - `devops-tnk-domain.postman_environment.json` (ตัวแปรสำหรับโดเมน `https://backend.group3.vec`)
   - `devops-tnk-localhost.postman_environment.json` (ตัวแปรสำหรับ `http://localhost:5000`)
3. **เลือก Environment ที่มุมขวาบน:**
   - เลือก **`DevOps TNK (Domain: backend.group3.vec)`**

> ⚡ **จุดเด่นพิเศษ (Auto Token):**  
> เมื่อกดยิงข้อ **`1.1 Login ด้วย Admin`** ระบบจะมีสคริปต์อัตโนมัติคอยดูด Token ไปเก็บในตัวแปร `{{token}}` และ `{{admin_token}}` ให้ทันที ทำให้ข้ออื่นๆ หลังจากนั้นสามารถกด **Send** ยิงได้ทันทีโดยไม่ต้องเสียเวลาก๊อปปี้ Token มาแปะเอง!

## 📁 โครงสร้างโฟลเดอร์ใน Postman (แยกตามรหัสเกณฑ์ในใบประเมินชัดเจน 100%)

เวลาเปิดใน Postman คุณจะเห็นโฟลเดอร์ถูกตั้งชื่อตรงตามข้อของใบประเมิน กรรมการตรวจข้อไหน ให้คลิกเปิดโฟลเดอร์ข้อนั้นได้เลย:

```text
📦 DevOps TNK - RESTful API Test Suite (แยกตามข้อใบประเมิน ปวส.)
 ├── 📁 [เกณฑ์ 4.5.4 & 4.4.5] API Login ด้วย JWT Token (ออก Token & มีลายเซ็น)
 ├── 📁 [เกณฑ์ 4.5.1] API แบบ GET (Query & Path Parameters)
 ├── 📁 [เกณฑ์ 4.5.2 & 4.5.6] API แบบ POST (JSON Body & บันทึกลง MySQL)
 ├── 📁 [เกณฑ์ 4.5.3] API สำหรับอัปโหลดไฟล์ (multipart/form-data)
 ├── 📁 [เกณฑ์ 4.4.1 & 4.5.7] Service แบบ PUT และ PATCH (แก้ไขข้อมูล)
 ├── 📁 [เกณฑ์ 4.4.1 & 4.5.7] Service แบบ DELETE (ลบข้อมูล)

 └── 📁 [เกณฑ์ 4.5.10 & 4.4.4] ความปลอดภัยและตรวจสอบสิทธิ์ (401 & 403)
```

## 🎯 4. วิธีสาธิตตอบคำถามกรรมการแบบไวที่สุด

1. **กรรมการขอดูเรื่อง Login & JWT Token (เกณฑ์ 4.5.4):**
   * 👉 เปิดโฟลเดอร์ **`[เกณฑ์ 4.5.4 & 4.4.5]`** ➔ กดยิง `1.1 Login ด้วย Admin` ➔ ได้ Token ทันที
2. **กรรมการขอดู API แบบ GET รับค่า Query & Path (เกณฑ์ 4.5.1):**
   * 👉 เปิดโฟลเดอร์ **`[เกณฑ์ 4.5.1]`** ➔ กดยิง `2.2 search=admin` หรือ `2.5 ID: 1`
3. **กรรมการขอดู API บันทึกข้อมูล POST ลงฐานข้อมูล (เกณฑ์ 4.5.2):**
   * 👉 เปิดโฟลเดอร์ **`[เกณฑ์ 4.5.2 & 4.5.6]`** ➔ กดยิง `3.1 เพิ่มผู้ใช้ใหม่` ได้ `201 Created`
4. **กรรมการขอดูการอัปโหลดไฟล์ (เกณฑ์ 4.5.3):**
   * 👉 เปิดโฟลเดอร์ **`[เกณฑ์ 4.5.3]`** ➔ กดยิง `4.1 อัปโหลดไฟล์` และเปิดดูที่ `4.2`
5. **กรรมการขอดูการจัดการ Error / Exception (เกณฑ์ 4.5.5):**
   * 👉 เปิดโฟลเดอร์ **`[เกณฑ์ 4.5.5]`** ➔ กดยิง `7.1` (ตอบ 400), `7.2` (ตอบ 404), `7.3` (ตอบ 409)
6. **กรรมการขอดูระบบตรวจสิทธิ์ 401 และ 403 (เกณฑ์ 4.5.10):**
   * 👉 เปิดโฟลเดอร์ **`[เกณฑ์ 4.5.10 & 4.4.4]`** ➔ กดยิง `8.1` (ไม่ส่ง Token ตอบ 401), `8.2` (สิทธิ์ไม่พอตอบ 403)
