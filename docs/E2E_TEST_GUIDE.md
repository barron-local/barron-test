# คู่มือการทดสอบ End-to-End (E2E) Test ด้วย Playwright
**มาตรฐาน:** ออกแบบตามเกณฑ์การประเมินทักษะ DevOps (หัวข้อการทดสอบ Workflow E2E)  
**คุณสมบัติพิเศษ:** **รันแบบ Offline ได้ 100% แม้ไม่มีอินเทอร์เน็ต** โดยใช้ Google Chrome ของเครื่องโดยตรง ไม่ต้องดาวน์โหลดเบราว์เซอร์เพิ่ม

---

## 📋 รายการกรณีทดสอบ E2E (Test Scenarios)

| รหัสทดสอบ | กรณีทดสอบ (Workflow) | สิ่งที่ตรวจสอบ |
| :--- | :--- | :--- |
| **`E2E-001`** | **ผู้ใช้เข้าสู่ระบบสำเร็จ** | กรอก `admin`/`admin` -> กดเข้าสู่ระบบ -> ตรวจพบหน้า Dashboard และชื่อ Admin |
| **`E2E-002`** | **ผู้ใช้ส่งข้อมูลสำเร็จ (Create Form)** | กรอกฟอร์มเพิ่มสมาชิกใหม่ -> กดบันทึก -> ตรวจพบชื่อผู้ใช้ใหม่ในตาราง |
| **`E2E-003`** | **ค้นหาและกรองข้อมูล (Search & Filter)** | กรอกชื่อในช่องค้นหา -> กดค้นหา -> ผลลัพธ์ในตารางกรองถูกต้อง |
| **`E2E-004`** | **ออกจากระบบสำเร็จ (Logout)** | กดปุ่มออกจากระบบ -> หน้าจอกลับสู่ฟอร์ม Login |

---

## 🚀 วิธีสั่งรัน E2E Test (เลือกได้ 3 แบบ)

### 1. รันแบบเปิดหน้าต่าง Chrome ให้กรรมการดูการทำงานอัตโนมัติ (Headed)
```bash
npm run test:e2e
# หรือ
npx playwright test
```
*ระบบจะเปิดหน้าต่าง Google Chrome ขึ้นมา พิมพ์ กรอก และคลิกตาม Workflow ให้อัตโนมัติทีละขั้นตอน*

### 2. รันแบบมี UI Dashboard สวย ๆ (เห็น Timeline และภาพแต่ละ Step)
```bash
npm run test:e2e:ui
# หรือ
npx playwright test --ui
```

### 3. เปิดดูรายงานสรุปผลพร้อมรูปภาพแคปหน้าจอ (HTML Report & Screenshots)
หลังจากรันเสร็จ สามารถเปิดดูผลลัพธ์พร้อมรูปภาพหลักฐานได้ด้วยคำสั่ง:
```bash
npm run test:e2e:report
```
*(ไฟล์รูปภาพหลักฐานจะถูกเซฟอัตโนมัติไว้ที่โฟลเดอร์ `playwright-report/screenshots/`)*

## 🌐 การเปลี่ยน URL ทดสอบ (กรณีทดสอบผ่าน Localhost หรือ IP)

ค่าเริ่มต้นถูกตั้งไว้ที่ `https://frontend.group3.vec` หากต้องการทดสอบกับ `localhost:3000` สามารถส่งตัวแปร Environment ได้ง่าย ๆ:

```powershell
$env:BASE_URL="http://localhost:3000"; npm run test:e2e
```
